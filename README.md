# AkademikAI - Mini RAG Demo

**AkademikAI** adalah asisten AI untuk mahasiswa S1 semester 5-7 yang membantu menjawab pertanyaan tentang penulisan laporan akademik, tugas akhir, dan proposal penelitian.

## Fitur
- Membaca 3 dokumen PDF (Panduan Skripsi, Silabus, Rubrik)
- Menjawab pertanyaan dengan **sumber file + halaman**
- Guardrails anti-halusinasi (G1-G4)
- Evaluasi otomatis dengan tabel

## Cara Menjalankan

```bash
# Aktifkan virtual environment
venv\Scripts\activate

# Jalankan program
python akademikai.py
