# AkademikAI - Mini RAG Demo

**AkademikAI** adalah asisten AI untuk mahasiswa S1 semester 5-7 yang membantu menjawab pertanyaan tentang penulisan laporan akademik, tugas akhir, dan proposal penelitian.

---

## 📋 Fitur

- Membaca 3 file PDF
- Memotong teks menjadi 30 chunk
- Membuat embedding dengan Sentence Transformers
- Pencarian semantik dengan ChromaDB
- Setiap jawaban disertai **sumber file**
- **Disclaimer anti-plagiarisme** di setiap jawaban

---
